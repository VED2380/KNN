
# 📊 K-Nearest Neighbors (KNN) Demo

## 📁 Project Structure

```text
.
├── iris_k_nearest.ipynb           # KNN on Iris dataset (classification)

└── README.md                      # Project documentation
```

---

## 🚀 Notebooks

### 🔹 Iris Classification
- **File**: `iris_k_nearest.ipynb`
- **Dataset**: Iris dataset
- **Goal**: Predict species using petal/sepal features
- **Highlights**:
  - Data visualization
  - KNN model training
  - Accuracy evaluation

### 🔹 General KNN Classifier
- **File**: `k_nearest_classifier.ipynb`
- **Dataset**: Custom or synthetic
- **Goal**: Multi-class classification
- **Highlights**:
  - Preprocessing pipeline
  - Classification report and confusion matrix

### 🔹 KNN Regressor
- **File**: `k_nearest_regressor.ipynb`
- **Dataset**: Custom/synthetic
- **Goal**: Predict continuous values
- **Highlights**:
  - Model fitting with `KNeighborsRegressor`
  - Evaluation with RMSE/R²
